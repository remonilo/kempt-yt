# Kempt

## Develop

```sh
npm i
npm run dev      # watch build into dist/
npm run check    # typecheck
npm test
```

Load `dist/` as an unpacked extension (Chrome: chrome://extensions → Developer mode → Load unpacked; Firefox: about:debugging → Load Temporary Add-on → dist/manifest.json).

Adding a feature: see PLAN.md §4.1 and §5.
