---
title: Comment search
description: Filter the comments already loaded under a video.
---

A search icon sits at the right end of the sort chips row. Click it and a search field opens beside the chips. The fullscreen comments panel has the same row under its title. Type to filter: a comment stays if its text or author name contains every word you typed. Case and accents don't matter, so "cafe" finds "café".

Clear the field with ✕, or press Escape twice, to bring the chips back.

## What it searches

Only the comments YouTube has loaded. YouTube has no comment search, and loading every comment would cost requests and memory. While you search, Kempt lets YouTube load a few more pages, until 10 threads match or 100 are loaded. When nothing matches, a line says so.

A thread shows if its top comment or one of its open replies matches. If only a reply matches, the other replies hide.

## Settings

The switch is **Watch page → Comment search**, with no options. It works with Comment sort on or off: with sort off and Comment layout off, the field replaces YouTube's Sort by menu.

## How it works

Kempt hides the threads that miss with an attribute and never moves YouTube's comment elements, so YouTube keeps its own scrolling and loading. Nothing runs while the field is empty.
